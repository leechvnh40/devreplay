- [x] 2.1 实现 DeepSeek 设置页、模型 ID 配置及基于 Electron `safeStorage` 的独立 secrets 文件，测试 SQLite、日志和 JSON 序列化中均不存在 API Key。
- [x] 2.2 实现可注入的 `ModelProvider` 端口和基于 OpenAI JavaScript SDK 的 DeepSeek 薄适配器，配置 DeepSeek Base URL、`maxRetries: 0` 与取消信号，并使用 mock server 验证成功、401、429、超时、取消和 token usage 规范化。
- [x] 2.3 建立版本化提示词注册表、`model_runs` 审计模型与 SQLite 仓储，测试 Authorization header 被脱敏且原始响应、结构化结果和错误可追踪；应用接线与查询入口由 2.16 验收。
- [x] 2.4 实现 `ContextManifest` 的必需/可选片段选择及大小估算，测试被用户移除的片段不会进入最终 DeepSeek 请求。
- [x] 2.5 实现发送内容预览组件、取消和删减交互，并用组件测试验证未确认预览前不会调用发送回调；真实模型请求接线由 2.17 验收。
- [x] 2.6 实现复盘显式状态机与恢复规则，单元测试覆盖合法路径、非法跳转、失败重试和已完成状态不可静默回退。
- [x] 2.7 实现自由回忆抽取 schema、定向追问 schema 和最多一次结构修复请求，以录制 fixture 验证成功、无效 JSON 与二次失败降级。
- [x] 2.8 实现双栏复盘组件、结构化复盘卡和来源标识，并以组件及领域测试验证用户修正后当前值发生变化且保留原始来源；持久化与后续追问接线由 2.17 验收。
- [x] 2.9 实现诊断假设模型，包含证据、替代解释、置信度和验证计划，并测试单次模糊信号只能生成待确认假设。
- [x] 2.10 实现诊断确认、驳回和保留待验证的领域服务、持久化逻辑与交互组件，并以服务集成测试验证只有用户确认产生正式证据；桌面流程接线由 2.17 验收。
- [x] 2.11 实现 append-only `evidence_entries`、修正/撤销关系和可重建 `capability_projection`，属性测试验证重建结果与增量投影一致。
- [x] 2.12 加入首版前端/全栈/AI 应用能力骨架、用户确认新增细分节点及离散状态 UI，并测试界面不展示掌握百分比。
- [x] 2.13 实现确定性复盘完成检查清单与持久化服务，并以数据库服务集成测试验证缺少诊断处理或证据预览时无法完成，未知项与“无需训练”理由可满足门槛；公共 IPC 端到端验收由 2.18 完成。
- [ ] 2.14 建立可重复工程基线：统一 Node 测试与 Electron 运行所需的 `better-sqlite3` rebuild 边界，确保从干净依赖状态执行 format check、lint、typecheck 和全量 test 均可确定退出，并建立不含构建产物、数据库或凭据的首个 Git 基线提交。

- [ ] 2.16 将 `ContextManifest`、`AuditedModelRunner`、`SqliteModelRunAuditStore` 和 DeepSeek provider 接入 Electron main 应用服务，持久化 `context_manifest_items` 及复盘产物与模型运行的关联，并以仓储/服务测试验证删减内容不会发送、审计记录可由产物追溯且 API Key 不进入记录。
- [ ] 2.17 通过白名单 IPC 和真实持久化状态把发送预览、自由回忆抽取、结构化卡片修订、定向追问、诊断处理、证据预览、训练决策与完成门槛接入桌面主流程，验证现有孤立组件和服务均可从应用入口到达且重启后恢复当前阶段。
